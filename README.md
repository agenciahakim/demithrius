# Landing page Vinicius Beccari

Landing page frontend-only em React, Vite e GSAP. As respostas do quiz são montadas localmente e só chegam ao profissional se o visitante confirmar o envio no WhatsApp.

## Executar

```bash
npm install
npm run dev
```

Para gerar a versão estática:

```bash
npm run build
```

## Antes de publicar

- Confirmar a grafia pública e o cargo de Vinicius, além de qualquer alegação pessoal que venha a ser acrescentada.
- Se houver, substituir o JPEG da marca por arquivo oficial SVG ou PNG transparente.
- Informar o domínio final para configurar canonical, URLs Open Graph e sitemap.xml.
- Revisar os textos comerciais e regulatórios com o profissional.
